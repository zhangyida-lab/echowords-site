# EchoWords public website

Published at https://zhangyida-lab.github.io/echowords-site/.

This repository contains only static public website files. Content is synchronized
from the private application repository's `dev` branch, `privacy-page/` directory.
Make content changes in the source repository; direct edits here are overwritten
by the next synchronization. GitHub Pages publishes the root of `main`.

The legacy privacy policy remains at
https://zhangyida-lab.github.io/echowordPrivacy/.
